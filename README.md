# 온마음 심리상담소 CRM 웹 애플리케이션 (Serenity CRM)

온마음 심리상담소의 내담자 회원가입, 맞춤 심리상담 신청, 관리자 전용 내담자 관리 및 심리상담 프로그램 설문지 커스텀 시스템을 제공하는 통합 웹 애플리케이션입니다.

---

## 🌿 주요 기능

### 1. 내담자 포털
- **회원가입 & 스마트 계정 연동 (`#/signup`)**:
  - 비밀번호 8자 이상, 숫자 필수 포함 유효성 검사 및 SHA-256 단방향 암호화 저장.
  - 관리자가 사전에 데스크에서 등록해 둔 내담자가 회원가입 시 이름/생년월일/전화번호가 일치하면 기존 레코드 자동 매핑 및 연동.
- **로그인 (`#/login`)**: 아이디 및 암호화 비밀번호 기반 안전한 로그인.
- **상담 프로그램 선택 (`#/select`)**:
  - 관리자가 활성화(ON)한 상담 프로그램 전체 노출.
  - 관리자가 사전 배정한 상담 프로그램이 있는 경우 '관리자가 배정한 상담' 뱃지 표시.
- **맞춤 설문지 작성 (`#/questionnaire`)**: 동적 객관식/주관식 설문 응답 및 제출.
- **완료 화면 (`#/success`)**: 자동 카운트다운 후 메인 화면 복귀.

### 2. 관리자 포털
- **관리자 등급 권한(RBAC) 시스템**:
  - 👑 **최고 관리자 (Super Admin)**: 내담자 삭제, 상담지 관리, 관리자 계정 등록/설정/삭제 등 모든 기능 제어.
  - 👤 **일반 관리자 (General Admin)**: 내담자 목록 조회, 상담 배정, 상담 기록 작성만 가능 (내담자 삭제, 상담지 관리, 관리자 관리, 내담자 등록 메뉴 접근 차단).
- **내담자 관리 (`#/admin/customerlist`)**:
  - 내담자 성명, 생년월일, 전화번호, 등록일자, 상담 기록 여부, 배정 상태 테이블.
  - 실시간 검색 필터링 및 상세 슬라이드 서랍장(Drawer).
  - 서랍장을 통한 상담 배정, 상담 노트 작성/수정/삭제, 진행 상태(대기중/진행중/완료) 변경.
- **상담지 관리 (`#/admin/administration`)**:
  - 상담 프로그램 추가/수정, 활성화 토글(ON/OFF).
  - 동적 질문지 에디터 (객관식 보기 추가, 주관식 문항 추가).
- **관리자 계정 관리 (`#/admin/managers`)**:
  - 전체 관리자 목록 및 등급 통계 현황.
  - 관리자 신규 등록 및 비밀번호 2중 확인 설정 모달, 계정 삭제.

## 🛠️ 기술 스택
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS (CDN), Material Symbols Icons
- **Database & Storage**: Firebase Firestore (온라인 모드) / LocalStorage (오프라인 로컬 모드) 하이브리드 지원
- **Security**: Web Crypto API (SHA-256 해시)
- **Architecture**: Single Page Application (Hash-based Routing)
